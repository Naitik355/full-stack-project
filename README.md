# Full Stack Project

A full-stack web development project featuring interactive applications, collaborative drawing, and collaborative document editing.

## Project Overview

This repository contains multiple full-stack development modules, including a frontend, backend, Excalidraw collaboration, and collaborative document functionality.

The project focuses on building interactive web applications, implementing client-server communication, and exploring real-time collaboration.

## Features

- **Full Stack Architecture** — Separate frontend and backend for modular development.
- **Collaborative Drawing** — Excalidraw-based module for interactive drawing and collaboration.
- **Collaborative Documents** — Document collaboration functionality developed as part of the ConvergeDesk project.
- **Modular Project Structure** — Organized components for easier development and maintenance.
- **Interactive User Experience** — Focus on responsive interfaces and collaborative workflows.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Naitik355/full-stack-project.git
```

### 2. Navigate to the Project Directory

```bash
cd full-stack-project
```

### 3. Frontend Setup

```bash
cd frontend
npm install
```

Run the development server using the script configured in the frontend's `package.json`.

### 4. Backend Setup

Open another terminal:

```bash
cd backend
npm install
```

Start the backend using its configured development or start script.

### 5. Environment Configuration

Configure the required environment variables for each application module before running the project.
